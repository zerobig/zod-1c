# zod-1c

Декларативная валидация данных для 1С:Предприятие 8.3 в стиле библиотеки Zod.
Схемы описываются fluent-цепочкой, результат проверки содержит данные и
структурированный список ошибок с путями до каждого невалидного поля.

Библиотека не требует БСП, XDTO, внешних компонент и дополнительных
зависимостей. Используется самостоятельно или совместно с библиотекой
`swagger-1c` для рантайм-валидации запросов по описанию OpenAPI.

## Статус

Бета. API стабилен, но возможны уточнения до релиза 1.0.0.

## Требования

- Платформа 1С:Предприятие 8.3.23 и выше (используются регулярные выражения).

## Установка

### Вариант 1: расширение (рекомендуется)

Скачайте последний релиз `zod-1c.cfe` и установите через Конфигуратор:
Конфигурация - Расширения конфигурации - Добавить из файла.

### Вариант 2: копирование исходников

Скопируйте в вашу конфигурацию или расширение:

- общий модуль `Zod` (Сервер, Вызов сервера);
- обработка `Zod_Схема` (модуль объекта);
- обработка `Zod_Трансформер_Телефон` (модуль объекта, опционально);
- обработка `Zod_Трансформер_ПустоеВНеопределено` (модуль объекта, опционально).

## Быстрый старт

```bsl
Схема = Zod.СтрогийОбъект()
    .Поле("clientId", Zod.Строки().Непустая().МаксДлина(50))
    .Поле("email",    Zod.Email())
    .Поле("amount",   Zod.ПриведенноеЧисло().Положительное())
    .Поле("comment",  Zod.Строки().МаксДлина(200).Необязательное());

Результат = Схема.Проверить(Данные);

Если Не Результат.Успех Тогда
    // Результат.Ошибки - массив структур {Путь, Сообщение}
    Возврат ОтветОшибкиВалидации(422, Результат.Ошибки);
КонецЕсли;

// Результат.Данные - проверенная и приведённая Структура
ОбработатьЗаказ(Результат.Данные);
```

## Результат проверки

```bsl
Результат = Схема.Проверить(Значение);

Результат.Успех     // Булево
Результат.Данные    // Проверенное и приведённое значение или Неопределено
Результат.Ошибки    // Массив из Структура("Путь, Сообщение")
```

Для проверки с выбросом исключения при ошибке:

```bsl
Данные = Схема.ПроверитьИлиВыбросить(Значение);
```

## API Reference

### Примитивы

| Фабрика | Возвращает | Пример |
|---|---|---|
| `Zod.Строки()` | Строка | `Zod.Строки().Непустая()` |
| `Zod.Числа()` | Число | `Zod.Числа().Целое()` |
| `Zod.Булевы()` | Булево | `Zod.Булевы()` |
| `Zod.Даты()` | Дата | `Zod.Даты()` |
| `Zod.Любое()` | Любое значение | `Zod.Любое()` |

Имена в множественном числе выбраны намеренно: `Строка`, `Число`,
`Булево`, `Дата`, `Массив` зарезервированы платформой как функции
преобразования типа.

### Объекты

| Фабрика | Возвращает | Неизвестные ключи |
|---|---|---|
| `Zod.Объект()` | Структура или Соответствие | Отбрасываются |
| `Zod.СтрогийОбъект()` | Структура или Соответствие | Ошибка |
| `Zod.СвободныйОбъект()` | Структура или Соответствие | Сохраняются |
| `Zod.Запись(СхемаКлюча, СхемаЗначения)` | Соответствие | Проверяются все ключи |

```bsl
Схема = Zod.Объект()
    .Поле("name", Zod.Строки().Непустая())
    .Поле("age",  Zod.Числа().Целое().МинЗначение(0));

СхемаЗаписи = Zod.Запись(Zod.Строки(), Zod.Числа().МинЗначение(0));
// Принимает {"M10": 100, "M12": 50} -> Соответствие
```

### Коллекции

| Фабрика | Пример |
|---|---|
| `Zod.Массивы()` | `Zod.Массивы().Элемент(Zod.Числа()).МинЭлементов(1)` |
| `Zod.Перечисление(Массив)` | `Zod.Перечисление(Значения)` |
| `Zod.Объединение(Массив)` | `Zod.Объединение(МассивСхем)` |

### Модификаторы строк

| Метод | Описание |
|---|---|
| `.МинДлина(n)`, `.МаксДлина(n)` | Ограничения длины |
| `.Непустая()` | Запрет пустой строки |
| `.Паттерн(Регулярка)` | Проверка регулярным выражением |
| `.Email()`, `.URL()`, `.UUID()` | Встроенные форматы |
| `.IPv4()`, `.IPv6()`, `.ДатаISO()` | Форматы сети и даты |
| `.ХешMD5()`, `.ХешSHA256()` | Хеши |
| `.Телефон()` | Телефон РФ (+7 / 8) |
| `.ИНН()`, `.ИНН10()`, `.ИНН12()` | ИНН с контрольной суммой |
| `.СНИЛС()`, `.ОГРН()`, `.ОГРНИП()` | С контрольной суммой |
| `.КПП()`, `.БИК()`, `.РасчетныйСчет()` | Банковские реквизиты |
| `.ОКТМО()`, `.ОКПО()` | Коды статистики |
| `.Луна()` | Номер карты по алгоритму Луна |
| `.EAN13()`, `.EAN8()`, `.ISBN10()`, `.ISBN13()` | Штрих-коды |

Все строковые форматы доступны и как отдельные фабрики:

```bsl
Zod.Email()     // то же, что Zod.Строки().Email()
Zod.ИНН()       // то же, что Zod.Строки().ИНН()
Zod.Телефон()   // то же, что Zod.Строки().Телефон()
```

### Модификаторы чисел

| Метод | Описание |
|---|---|
| `.МинЗначение(n)`, `.МаксЗначение(n)` | Границы |
| `.Целое()` | Только целые числа |
| `.Положительное()` | Строго больше нуля |

Имена `.МинЗначение()` и `.МаксЗначение()` выбраны так, потому что `Мин`
и `Макс` зарезервированы платформой как встроенные функции.

### Приведение типов

| Фабрика | Приведение |
|---|---|
| `Zod.ПриведеннаяСтрока()` | Любое значение к строке |
| `Zod.ПриведенноеЧисло()` | Строка или число к числу |
| `Zod.ПриведенноеБулево()` | Строка, число, булево к булеву |
| `Zod.ПриведеннаяДата()` | Строка или дата к дате |

```bsl
Zod.ПриведенноеЧисло().Проверить("123").Данные // 123 (Число)
Zod.ПриведенноеЧисло().Проверить("abc").Успех  // Ложь
```

### Обязательность и null

По умолчанию все поля обязательны. Управление обязательностью и
допустимостью значения `Неопределено` (в JSON - `null`) выполняется
двумя модификаторами.

| Модификатор | Ключ может отсутствовать | Значение может быть Неопределено |
|---|---|---|
| (без модификатора) | Нет | Нет |
| `.ДопускаетNull()` | Нет | Да |
| `.Необязательное()` | Да | Да |
| `.ДопускаетNull().Необязательное()` | Да | Да |

`Zod.Строки().Необязательное()` в объекте разрешает и отсутствие ключа,
и значение `Неопределено`. Это соответствует `.nullish()` в Zod
(TypeScript), а не `.optional()`. Для строгой семантики `.optional()`
используйте `.ДопускаетNull()` в комбинации с явной проверкой.

Утилиты для программной проверки:

```bsl
Схема.ДопускаетОтсутствие()   // Истина, если ключ может отсутствовать
Схема.ДопускаетНеопределено() // Истина, если значение может быть Неопределено
```

### Ссылочные типы 1С

| Фабрика | Принимает | Возвращает |
|---|---|---|
| `Zod.Справочник("Имя")` | UUID-строку, структуру `{type, id}` или ссылку | `СправочникСсылка.Имя` |
| `Zod.Документ("Имя")` | то же | `ДокументСсылка.Имя` |
| `Zod.ПеречислениеСсылка("Имя")` | то же | `ПеречислениеСсылка.Имя` |
| `Zod.ПланВидовХарактеристик("Имя")` | то же | соответствующая ссылка |
| `Zod.ПланСчетов("Имя")`, `Zod.ПланОбмена("Имя")` | то же | соответствующая ссылка |
| `Zod.БизнесПроцесс("Имя")`, `Zod.Задача("Имя")` | то же | соответствующая ссылка |
| `Zod.ЛюбаяСсылка()` | только структуру `{type, id}` | любая ссылка 1С |
| `Zod.СоставнаяСсылка("Тип1")` | структуру `{type, id}` из списка | ссылка одного из типов |

```bsl
// Один тип - можно короткий UUID
Zod.Справочник("Номенклатура")
    .Проверить("a1b2c3d4-...") // -> СправочникСсылка.Номенклатура

// Составная ссылка - только структура {type, id}
Zod.СоставнаяСсылка("Справочник.Пользователи")
    .ИлиСсылка("Справочник.ВнешниеПользователи")
    .Проверить(Новый Структура("type, id", "Справочник.Пользователи", "..."))
```

Модификатор `.ТолькоСуществующая()` возвращает ошибку, если объект с таким
UUID отсутствует в базе.

### Объекты 1С

| Фабрика | Возвращает |
|---|---|
| `Zod.ОбъектДокумента("Имя")` | `ДокументОбъект.Имя` |
| `Zod.ОбъектСправочника("Имя")` | `СправочникОбъект.Имя` |
| `Zod.ОбъектПланаВидовХарактеристик("Имя")` | соответствующий объект |
| `Zod.ОбъектПланаСчетов("Имя")`, `Zod.ОбъектПланаОбмена("Имя")` | соответствующий объект |
| `Zod.ОбъектБизнесПроцесса("Имя")`, `Zod.ОбъектЗадачи("Имя")` | соответствующий объект |

```bsl
Схема = Zod.ОбъектДокумента("ЗаказКлиента")
    .ЗаполнятьПоУмолчанию()
    .Поле("Контрагент", Zod.Справочник("Контрагенты").ТолькоСуществующая())
    .Поле("СуммаДокумента", Zod.Числа().МинЗначение(0))
    .ТабличнаяЧасть("Товары",
        Zod.СтрогийОбъект()
            .Поле("Номенклатура", Zod.Справочник("Номенклатура"))
            .Поле("Количество", Zod.Числа().Целое().Положительное())
            .Поле("Цена", Zod.ПриведенноеЧисло().Положительное()));

Результат = Схема.Проверить(Данные);
// Результат.Данные - заполненный ДокументОбъект.ЗаказКлиента
```

```bsl
// Сериализация для JSON-ответа
Zod.СериализоватьСсылку(Ссылка)     // -> {type: "Справочник.X", id: "uuid"}
```

### Параметры URL (query string)

HTTP-сервисы часто принимают данные в query string. В 1С
`Запрос.ПараметрыЗапроса` - это `Соответствие`, где все значения приходят
строками. Для единой валидации с JSON-телом используется адаптер
`Zod.ПроверитьПараметрыЗапроса()`.

```bsl
Функция СписокТоваровGET(Запрос) Экспорт

    СхемаПараметров = Zod.СтрогийОбъект()
        .Поле("page",  Zod.ПриведенноеЧисло().Целое().МинЗначение(1).Необязательное())
        .Поле("limit", Zod.ПриведенноеЧисло().Целое().МаксЗначение(100).Необязательное())
        .Поле("sort",  Zod.Перечисление(МассивСортировок()).Необязательное());

    Результат = Zod.ПроверитьПараметрыЗапроса(Запрос, СхемаПараметров);
    Если Не Результат.Успех Тогда
        Возврат ОтветОшибкиВалидации(400, Результат.Ошибки);
    КонецЕсли;

    Возврат ОтветJSON(200, ПостроитьСписок(Результат.Данные));

КонецФункции
```

Адаптер передаёт `ПараметрыЗапроса` (`Соответствие`) в схему напрямую,
без промежуточной структуры. Ключи сохраняются как есть, включая имена,
невалидные для `Структуры` (`user-id`, `filter.name`). Результат проверки
возвращается в `Результат.Данные` как `Соответствие`.

Для чисел, булевых и дат в query обязательно используйте приведение
(`Zod.ПриведенноеЧисло()`, `Zod.ПриведенноеБулево()`, `Zod.ПриведеннаяДата()`).
Для строк, `Zod.UUID()` и `Zod.Перечисление()` приведение не требуется.

## Кастомные проверки и трансформеры

### Проверки

Проверка - это объект с методом `Проверить(Значение)`, который возвращает
одно из:

- `Истина` - валидно;
- `Ложь` - невалидно, стандартное сообщение;
- `Строка` - невалидно, строка используется как сообщение;
- `Структура("Валидно, Сообщение")` - явный вариант;
- `Неопределено` - проверка не применима, пропускается.

```bsl
// Обработка МояПроверка, модуль объекта
Функция Проверить(Значение) Экспорт
    Если Значение.Количество() > 100 Тогда
        Возврат "Слишком много элементов";
    КонецЕсли;
    Возврат Истина;
КонецФункции

// Использование
Zod.Массивы()
    .Элемент(Zod.Числа())
    .Проверка(Обработки.МояПроверка.Создать())
```

Проверки применяются только в том случае, если базовая валидация прошла
без ошибок.

### Трансформеры

Трансформер - это объект с методом `Преобразовать(Значение)`, который
возвращает новое значение. Применяется до валидации.

```bsl
// Нормализация телефона: "8 (999) 123-45-67" -> "+79991234567"
Zod.Строки()
    .Трансформировать(Обработки.Zod_Трансформер_Телефон.Создать())
    .Телефон()
```

Готовая фабрика:

```bsl
Zod.НормализованныйТелефон()
```

Трансформеры комбинируются:

```bsl
Zod.Строки()
    .Трансформировать(Обработки.Zod_Трансформер_ПустоеВНеопределено.Создать())
    .Трансформировать(Обработки.Zod_Трансформер_Телефон.Создать())
    .Телефон()
```

## Известные ограничения

1. В общих модулях 1С нет переменных модуля. `Zod_Схема` - это обработка,
   поэтому каждая схема является независимым объектом. Кэширование схем
   в общем модуле невозможно; при необходимости кэш организуется на уровне
   вызывающего кода.

2. `.Необязательное()` в zod-1c ведёт себя как `.nullish()` в Zod
   (TypeScript): пропускает и отсутствие ключа, и `Неопределено`. Для
   строгой семантики `.optional()` (только отсутствие) используйте
   `.ДопускаетNull()` в комбинации с явной проверкой.

3. `.Паттерн()` работает как `RegExp.test()` в JavaScript: ищет совпадение
   в любом месте строки. Для проверки полного соответствия используйте
   явные анкоры `^...$`.

4. Приведение числа: `Число("")` в 1С выбрасывает исключение, а не
   возвращает 0. Пустая строка не приводится к числу, валидация выдаёт
   ошибку. Для «мягкой» трактовки используйте трансформер
   `Zod_Трансформер_ПустоеВНеопределено` в комбинации с `.Необязательное()`.

5. Приведение числа в русской локали: `Число("1.5")` даёт `15`, а не `1.5`
   (точка интерпретируется как разделитель разрядов). В английской локали
   поведение противоположное.

6. Имена фабрик выбраны в множественном числе, чтобы не пересекаться с
   функциями платформы: `Строки`, `Числа`, `Булевы`, `Даты`, `Массивы`.
   Аналогично `.МинЗначение()` и `.МаксЗначение()` вместо `.Мин()` и
   `.Макс()`.

## Совместимость с swagger-1c

Библиотека `swagger-1c` (начиная с версии 2.0.0) использует `zod-1c` для
рантайм-валидации запросов через модуль `Swag_ZodАдаптер`. При этом:

- `swagger-1c` работает без `zod-1c` (генерация спецификации не требует
  валидации);
- `zod-1c` работает без `swagger-1c` (это независимые библиотеки);
- при совместной установке `Swag_ZodАдаптер` автоматически определяет
  наличие `zod-1c` и использует его функции.
